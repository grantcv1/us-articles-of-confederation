# Articles of Confederation in Akoma Ntoso

The Articles of Confederation, the first constitution of the United States, in Akoma Ntoso XML, with a CSS stylesheet that renders the document in a parchment style in a web browser. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `articles-of-confederation.xml` | The Akoma Ntoso document |
| `articles-of-confederation.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** The greeting and recited title are in `<preamble>`. The 13 articles are in `<body>`, with `<clause>` elements where an article has several paragraphs. The clause numbers are editorial. The ratification and signatures are in `<conclusions>`.
- **Signatures:** The 48 signatures are base64-encoded PNG images in `<img>` elements within `<signature>`, grouped by state. Each has a `<person>` element with the signer's full name.
- **Rendering:** Browsers do not draw Akoma Ntoso `<img>` elements. The stylesheet draws one ink image of the signature block, which also keeps the state labels, braces and dates, and places invisible, selectable names over the signatures. Some faded signatures remain hard to read.
- **Dates:** The Work date is the adoption date, November 15, 1777. The ratification date in the text, July 9, 1778, is marked with `<date>`. The dates individual delegates wrote beside their names are in the image only.

## Sources

- Text: the U.S. National Archives [transcript](https://www.archives.gov/milestone-documents/articles-of-confederation). Spelling and punctuation follow it, including "con-firmed" in Article XIII.
- Signatures, state labels: the National Archives [scan](https://catalog.archives.gov/id/301687) of the sixth sheet.
- Signer names: the National Archives transcript does not list the signers. Their names were matched by Claude from the scan and general knowledge and written in full, so they should be checked against a published list.

## Fonts

The stylesheet embeds Pinyon Script and UnifrakturCook, both licensed under the [SIL Open Font License](https://openfontlicense.org/). The fonts approximate the original hand; they do not reproduce it.
