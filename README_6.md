# Te Tiriti o Waitangi in Akoma Ntoso

Te Tiriti o Waitangi, the Treaty of Waitangi of 1840, in Akoma Ntoso XML, with its Māori and English texts as parallel documents and a CSS stylesheet for reading them side by side. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `treaty-of-waitangi.xml` | The Akoma Ntoso document |
| `treaty-of-waitangi.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** A `<documentCollection>` holds two `<component>` elements, each with a complete `<doc>`: `tiriti` in Māori and `treaty` in English. Each has its own language expression and metadata.
- **Two texts:** The texts differ in meaning. `FRBRtranslation` is deliberately not used, and no key terms are mapped between them. The side-by-side layout follows article numbers only and does not claim equivalence.
- **Order:** The Māori text comes first.
- **Language:** `xml:lang` marks the Māori and English content. The Māori expression uses the language code `mao`.
- **Editorial headings:** The collection titles, date line, explanatory note and the "Te Reo Māori" and "English" headings are editorial.
- **Signatories:** The source ends with "[Here follow signatures, dates, etc.]" in English and "Ko nga Rangatira o te wakaminenga." in Māori. The signatories' names, marks and moko are not reproduced. Only William Hobson's name is marked up, because it appears in the source text.

## Source

Both texts follow Schedule 1 of the [Treaty of Waitangi Act 1975](https://www.legislation.govt.nz/act/public/1975/114/en/latest/), including its spelling and punctuation. The Māori text in that Schedule has no macrons. The Schedule's Māori text was replaced by the Treaty of Waitangi Amendment Act 1985. This is the statutory text, not a transcription of an original treaty sheet.
